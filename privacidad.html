Política de Privacidad

Última actualización: agosto de 2026

Esta Política de Privacidad explica qué información recopila este sitio, para qué se utiliza y cómo se procesa, principalmente a través del formulario de contacto.

Qué información recopilamos

Este sitio recopila únicamente la información que el cliente entrega voluntariamente a través del formulario de contacto: nombre, correo electrónico y el contenido del mensaje enviado. No se recopila ningún otro dato personal de forma automática.

Para qué se utiliza esta información

La información recibida a través del formulario se utiliza exclusivamente para responder a la consulta o solicitud del cliente. No se utiliza con fines de marketing, no se vende ni se comparte con terceros.

Cómo se procesa el formulario

El formulario de contacto de este sitio es procesado por un servicio externo (FormSubmit), que permite el envío de mensajes por correo electrónico sin necesidad de un servidor propio. Este servicio recibe los datos ingresados en el formulario únicamente para reenviarlos al correo de IRK.Studios.

Otros servicios externos

Este sitio utiliza Google Fonts para mostrar su tipografía, lo que puede implicar una solicitud a los servidores de Google al cargar la página. IRK.Studios no utiliza cookies de seguimiento ni herramientas de analítica o publicidad en este sitio.

Conservación de los datos

Los mensajes recibidos a través del formulario de contacto se conservan solo el tiempo necesario para dar respuesta a la consulta, salvo que exista una conversación o proyecto en curso con el cliente.

Derechos del usuario

Si enviaste un mensaje a través de este sitio y quieres solicitar la eliminación de tus datos, o tienes alguna duda sobre esta política, puedes escribir directamente a irk.studioss@gmail.com.
